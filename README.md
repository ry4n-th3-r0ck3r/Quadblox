# QuadBlox (In Progress...)

QuadBlox is a falling block puzzle game written in Python using Pygame.

This project serves two purposes:

- Build a polished desktop game from scratch.
- Practice object oriented programming, game architecture, collision detection, rendering, and software design.

## Status
Early development

## Planned Features

- Classic falling block gameplay
- Piece rotation
- Line clearing
- Score tracking
- Increasing difficulty
- High score saving
- Sound effects and music
- Clean, maintainable codebase

## Current Features
-Game board prints
-All game pieces are defined

## Technologies

- Python 3.12
- Pygame
- PyCharm
